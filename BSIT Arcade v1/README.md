# BSIT Arcade

**BSIT Arcade** is a campus game publishing and discovery hub. It lets BSIT students browse, publish, review, and play student-made games.

## Members

- Marc Celis
- Charles Martillano

## Repository structure

- `database/` - PostgreSQL/Supabase schema and sample data
- `docs/` - project brief, CRUD map, sitemap, user flow, wireframes, and style guide
- `prototype/` - static HTML/CSS list and form mock-ups

## View the prototype

Open `prototype/list.html` with Live Server. Use the navigation to open `prototype/form.html`.

Don't mind the `frontend/` folder sir.
